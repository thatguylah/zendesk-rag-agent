title: Using Northwind Cloud offline on mobile
category: Product Usage
---

The Northwind Cloud mobile app (iOS and Android) supports limited offline access.

When offline, you can:
- View previously loaded tasks and projects (cached from your last sync)
- Create new tasks and comments — these are queued locally

When offline, you cannot:
- See real-time updates from other users
- Upload attachments (these are queued but only begin uploading once you're back online)
- View projects you have not opened at least once while online

Queued changes sync automatically when connectivity is restored. If a conflicting edit was made by another user while you were offline (e.g. someone else also edited the same task), the app will show a conflict resolution screen letting you choose which version to keep, or merge manually.

Offline cache is limited to 30 days of activity per project to manage device storage.
