title: Reporting a suspected security issue
category: Data & Privacy
---

If you believe you've discovered a security vulnerability in Northwind Cloud, or suspect unauthorized access to your workspace, do not post details in a public support ticket or community forum.

Instead:
1. Email security@northwindcloud.example directly with a description of the issue.
2. For suspected account compromise, a Workspace Admin should immediately revoke active sessions for the affected user (Workspace Settings > Security > Active Sessions > Revoke) and rotate any API tokens that user had created.
3. Our security team acknowledges reports within 4 business hours and will follow up with next steps.

Northwind Cloud does not currently run a public bug bounty program, but responsible disclosures are credited in our security acknowledgments page if the reporter consents.

Support agents should never ask a customer to share passwords, API tokens, or SSO credentials in a ticket. If a customer includes these in a ticket by mistake, redact them from any reply and advise the customer to rotate the credential immediately.
